# Cómo y Cuándo Presentar una Reclamación

Una reclamación es el mecanismo formal para que un cliente reporte un problema con un envío y quede registrado con número de caso y SLA de respuesta. Existen cuatro tipos:

- **Retraso** — el envío superó los umbrales de `retrasos.md` y el cliente quiere que quede en investigación formal.
- **Daño** — ver `paquetes_danados.md`.
- **Pérdida** — normalmente se abre automáticamente al final de una investigación por retraso, ver `paquetes_perdidos.md`.
- **Cobro incorrecto** — diferencia entre la tarifa cotizada (ver `tarifas.md`) y lo efectivamente cobrado.

**Plazo para presentar una reclamación:** hasta 30 días calendario desde la fecha de admisión del envío. Pasado ese plazo, el caso puede escalarse a un agente humano pero ya no aplica el SLA estándar ni la indemnización automática.

**Información requerida para abrir una reclamación:**

1. Número de guía del envío.
2. Tipo de reclamación (uno de los cuatro anteriores).
3. Descripción breve del problema.
4. Evidencia cuando aplique (fotos para daño; no se requiere evidencia adicional para retraso, ya que el sistema la tiene por los eventos del envío).

Al abrirse, la reclamación recibe un número de caso (`Claim #`) y un SLA de respuesta de 5 días hábiles (3 días hábiles si es de tipo retraso, ver `retrasos.md`). Tanto el cliente como un agente con acceso a los datos del cliente pueden abrir una reclamación — no se requiere ningún rol especial más allá de poder identificar el envío y al cliente asociado.
